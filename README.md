# homebrew-tap

Homebrew formula for [devlanes](https://github.com/devlanes-run/devlanes) on macOS and Linux.

```sh
brew install devlanes-run/tap/devlanes
```

The formula installs `devlanes` and `devlanes-hosts`. The release workflow of `devlanes-run/devlanes` writes `Formula/devlanes.rb` for every stable release, so changes made here by hand are overwritten.

devlanes has no release yet. Until the first one, the formula is disabled and `brew install` stops with that message.
